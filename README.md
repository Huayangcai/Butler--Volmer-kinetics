
# Golden Competition States in Butler–Volmer Kinetics

MATLAB source code accompanying the accepted manuscript:

**Bishuang Chen and Huayang Cai**, *“Golden competition states in Butler–Volmer kinetics: exact asymmetry correction and a formal consistency bound,”* **Journal of Materials Chemistry A, DOI: 10.1039/D6TA07464B** (accepted manuscript, 2026).

## Overview

These scripts reproduce **Figures 1–3** and the **table-of-contents (TOC) graphic**. Within the complementary-coefficient Butler–Volmer (BV) model, the normalized golden competition states remain fixed at $(\beta_\phi,m_\phi)=(\pm 1/\sqrt{5},\,2/\sqrt{5})$, while kinetic asymmetry changes the golden-point current amplitude. The code illustrates the exact correction, formal consistency bounds, and internal consistency tests using published Pt/C hydrogen evolution/oxidation (HER/HOR) data.

## Requirements and usage

- **MATLAB R2020a or later** is recommended for the main figure scripts. No additional MATLAB toolboxes are required.
- Place `Experimental Data.xlsx` in the working directory when running `Figure03.m` (or select the file when prompted).
- Run the scripts from the repository directory:

```matlab
cd('/path/to/repository')

run('Figure01.m')
run('Figure02.m')
run('Figure03.m')
run('TOC_GoldenCompetition.m')
```

The scripts save high-resolution PNG and vector PDF/SVG files. Figures 1–3 and the CSV summaries are written to the current working directory; the TOC exports are written alongside its script.

## Notes on data and interpretation

- `Figure03.m` reads the **`Figure 7`** worksheet, range **`A10:AL581`**. As documented in the script, the numerical current values are treated as **mA cm⁻²**, despite the worksheet header stating A cm⁻², and are converted to A cm⁻² for calculations (`currentScale = 1e-3`). Current densities are normalized to the nominal **Pt surface area**, not geometric electrode area.
- Golden-point currents are obtained by interpolation within the available potential range; **no extrapolation** is used for missing golden points.
- The interval **$0.3\leq a\leq0.7$** is an illustrative physical-plausibility assumption, not a universal bound. The formal complementary-BV interval is **$0\leq a\leq1$**.
- Experimental comparisons use benchmarks derived from the same polarization records and therefore test **internal model consistency**, not independent mechanistic validation. The temperature and pressure subsets have different experimental conditions and are analyzed separately; reported bound violations should be interpreted with attention to experimental uncertainty.
